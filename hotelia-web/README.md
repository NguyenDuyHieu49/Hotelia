# Hotelia Web Admin Dashboard

## Setup

```bash
cd hotelia-web
npm install
npm run dev
```

## Access

- Open: http://localhost:5173
- Login with admin account

## Test Accounts

- **Admin**: admin@hotelia.com / Admin123!
- **Owner**: owner@hotelia.com / Owner123!

## Features

- Dashboard with stats
- Manage Hotels (approve/reject)
- Manage Owners (approve/reject)
- View Bookings
